# HR-Analytics-Dashboard
Recommended Structure and Order
📊 Key Features

### 📉 Attrition Analysis
* Track voluntary vs. involuntary turnover rates.
* Identify high-risk departments and roles.
* Pinpoint correlation between attrition, monthly income, and years at the company.

### 👥 Workforce Demographics
* Monitor gender balance, age distribution, and ethnicity metrics.
* Track diversity ratios across leadership vs. entry-level positions.

### 💼 Performance & Compensation
* Correlate performance ratings with salary hikes and promotions.
* Identify pay gaps or compensation anomalies across departments.
* Map employee satisfaction survey results against productivity.

## 🛠️ Tech Stack & Tools
**Data Cleaning & ETL:** Python (Pandas, NumPy), SQL
**Data Modeling:** Power Pivot / DAX (Power BI)
**Visualization:** Power BI / Tableau / Streamlit (Power BI)
**Dataset:** [HR_Analytics-Dataset.csv]
